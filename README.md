  <h3>🎯 Stock Price Prediction Platform — MAIN PROJECT</h3>

  **End-to-End ML-Powered Stock Prediction Dashboard | LSTM + FastAPI + Next.js**

- Built a full-stack ML platform with an LSTM-based model for stock price forecasting exposed via typed FastAPI REST APIs
- Developed a Next.js/React trading-style dashboard with interactive charts, real-time predictions, and market views
- Integrated Finnhub and Alpha Vantage market data APIs with local JSON fallback for demo and testing
- Containerized with Docker + docker-compose and deployed backend on Render, frontend on Vercel
- Engineered clean separation between ML inference, data pipeline, and frontend UI layers
