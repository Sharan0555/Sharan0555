  <h3>🎯 Stock Price Prediction Platform - MAIN PROJECT</h3>
 
 **End-to-End ML-Powered Stock Prediction Dashboard | LSTM + FastAPI + Next.js**
 
- Built full-stack ML platform with LSTM-based model for stock price forecasting exposed via typed FastAPI REST APIs
- Developed Next.js/React trading-style dashboard with charts, real-time predictions, and market views
- Integrated Finnhub and Alpha Vantage market data APIs with local JSON fallback for demo/testing
- Containerized with Docker + docker-compose, Nginx gateway, and Makefile helpers for smooth DX
- Deployed backend to Render and frontend to Vercel for free cloud hosting
- Tech Stack: Python, FastAPI, LSTM, Next.js, React, TypeScript, PostgreSQL, MongoDB, Docker
